# SCT
Sistema de Controle de Tarefas

O Sistema de Controle de Tarefas é uma aplicação web simples em HTML, CSS e JavaScript para organizar atividades do dia a dia.   
O sistema permite:Cadastrar usuário, fazer login, criar, editar, concluir e excluir tarefas.   Pode filtrar a lista de tarefas por status (pendente, em andamento ou concluída).
